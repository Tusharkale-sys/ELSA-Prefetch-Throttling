# Notice

ELSA adds a SARSA-based runtime prefetch-degree controller to the
Smart-Stride+Berti (sBerti) prefetching path.

The repository includes ELSA source, experimental summaries, analysis
scripts, portable reproduction helpers, RTL, and compact hardware
validation artifacts.

The work builds on Berti-related prior work. Upstream provenance and
the exact reference commit are documented in `provenance/UPSTREAM.md`.

Large benchmark traces, third-party toolchains, generated binaries,
private research material, and unrelated experimental work are not
distributed in this repository.
