# Results

## Canonical result set for the current paper

Use `results/final617/` for the current ELSA manuscript.

- `ELSA_FINAL617_raw_ipc.csv`: canonical 617-execution compact IPC ledger.
- `FINAL_617_JOB_MATRIX_PUBLIC.tsv`: frozen job matrix.
- `COMMON_ARGS.json`: common simulator arguments.
- `CLOSURE_PUBLIC.txt`: closure interpretation.
- `CAMPAIGN_COMPLETE.txt`: campaign completion marker.

The 617 executions are a ledger count, not an inferential `n=617`.

## Hardware

`results/hardware/final_h7/` contains compact evidence for the final H7 static-decode realization.

## Historical directories

Other result directories in this repository predate or support earlier stages of the research program. They are retained for lineage and should not be used as replacements for Final617 values in the current paper.
