# Provenance

This directory records the identity of the frozen software, traces, simulator binary, and hardware evidence used by the current ELSA paper.

## Final617

`provenance/final617/` contains:

- trace provenance,
- simulator-binary provenance,
- checkpoint manifest,
- status-file hashes,
- log-file hashes.

## Hardware

`provenance/hardware/H7_FINAL_MANIFEST.sha256` is copied from the frozen final hardware closure.

These files exist to make the public artifact auditable without rewriting or selectively rerunning the frozen campaign.
